## 引用原则

1. **只引单帧**，不引连续帧，不替代原作观看。
2. **用于评论**：本文分析的是画面属性（配色、节奏、位移），不是作品内容。
3. **标注来源**：能确认的写平台与作者；不能确认的如实写"未标注"，不臆测。
4. **可撤回**：任何原作者通过 issue 要求移除，24 小时内删除，不要求理由。
